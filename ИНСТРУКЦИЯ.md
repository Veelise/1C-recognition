# Инструкция по работе с программой

## Запуск программы

```bash
cd 1C-recognition
python db_app.py
```

---

## Подключение к БД

При запуске появится окно подключения. Введите параметры:

| Параметр | Значение                             |
| ---------------- | -------------------------------------------- |
| Host             | localhost (или адрес сервера) |
| Port             | 5432                                         |
| Database         | **shuvi_test**                         |
| User             | ваш пользователь PostgreSQL   |
| Password         | ваш пароль                          |

После нажатия "Подключиться" программа готова к работе.

---

## Workflow программы

Программа имеет 5 этапов работы с чертежами. Переключение между этапами — кнопки в верхней части окна.

### Этап 1: 📥 Загрузка

**Цель:** Загрузить PDF-чертеж в систему

**Порядок действий:**

1. **Выберите сотрудника** — кнопка "Выбрать сотрудника" в правом верхнем углу
2. Нажмите **"Загрузить чертеж"**
3. Выберите PDF-файл чертежа
4. Введите номер/название чертежа
5. Чертеж сохраняется в БД → автоматический переход к этапу 2

---

### Этап 2: 🔍 OCR

**Цель:** Распознать текст с чертежа

**Порядок действий:**

1. Выберите чертеж из списка (слева)
2. Нажмите **"Запустить OCR"**
3. Дождитесь распознавания (может занять 10-60 секунд)
4. Проверьте распознанный текст в поле справа
5. При необходимости отредактируйте данные
6. Нажмите **"Сохранить в БД"** — данные сохраняются в таблицу PRO

**Требования для OCR:**

- PyMuPDF
- Pillow
- opencv-python
- numpy
- easyocr

---

### Этап 3: ✏️ Проверка качества

**Цель:** Проверить качество распознавания

**Порядок действий:**

1. Выберите чертеж из списка
2. Нажмите:
   - **"Качество ОК"** — чертеж принят
   - **"Требует исправления"** — чертеж помечается для доработки

Чертежи с пометкой "Требует улучшения" можно исправить и повторно отправить на проверку.

---

### Этап 4: ✅ Валидация

**Цель:** Создать финальный результат (FRO)

**Порядок действий:**

1. Выберите PRO из списка (результат OCR)
2. Нажмите **"Валидировать"**
3. Создаётся запись в таблице FRO

После валидации чертеж готов к архивации.

---

### Этап 5: 📦 Архив

**Цель:** Перенести чертеж в архив

**Порядок действий:**

1. Выберите FRO из списка
2. Нажмите **"Архивировать"**
3. Чертеж переносится в ARCH_OF_DRAWS

## Таблицы БД и их назначение

| Таблица    | Назначение                       |
| ----------------- | ------------------------------------------ |
| EMPLOYEES         | Сотрудники системы        |
| SKETCH_DRAWINGS   | Эскизы (исходные файлы) |
| PRIMARY_DRAWINGS  | Первичные чертежи          |
| PRO               | Результаты OCR                   |
| FRO               | Финальные результаты    |
| ARCH_OF_DRAWS     | Архив                                 |
| DRAWING_TAMPLATES | Шаблоны ГОСТ                    |
| TEMPLATE_AREA     | Области шаблонов            |
| DRAWING_VERSIONS  | История исправлений      |

---

## Возможные ошибки

| Ошибка                             | Решение                                                                       |
| ---------------------------------------- | ------------------------------------------------------------------------------------ |
| "Нет подключения к БД"  | Проверьте параметры подключения                         |
| "Выберите сотрудника"  | Нажмите "Выберите сотрудника" перед загрузкой |
| "Модуль easyocr не найден" | Установите:`pip install easyocr`                                         |
| "Выберите чертеж"          | Выберите строку в списке слева                             |

## Установка зависимостей

```bash
pip install PyMuPDF Pillow opencv-python numpy easyocr psycopg2-binary
```

## Схема потока данных

```
PDF-файл
    ↓
Этап 1: Загрузка
    → SKETCH_DRAWINGS + PRIMARY_DRAWINGS
    ↓
Этап 2: OCR (EasyOCR)
    → PRO (распознанные данные)
    ↓
Этап 3: Проверка качества
    → PRIMARY_DRAWINGS.NeedToImprove
    ↓
Этап 4: Валидация
    → FRO (финальный результат)
    ↓
Этап 5: Архив
    → ARCH_OF_DRAWS
```
