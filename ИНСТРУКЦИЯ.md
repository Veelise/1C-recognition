## Workflow программы

Программа имеет 4 этапа работы с чертежами.

### Этап 1: 📥 Загрузка

**Цель:** Загрузить PDF-чертеж в систему

**Порядок действий:**

1. **Выберите сотрудника** — кнопка "Сотрудник" в правом верхнем углу
2. Нажмите **"Загрузить PDF"**
3. Выберите PDF-файл чертежа
4. Введите номер/название чертежа
5. Чертеж сохраняется в БД → автоматический переход к этапу 2

---

### Этап 2: 🔧 Предобработка

**Цель:** Оценить качество и подготовить изображение

**Порядок действий:**

1. Выберите чертеж из списка
2. Нажмите **"Обработать"** — система:
   - Оценит уровень искажений
   - Выполнит бинаризацию, выравнивание, удаление шума
3. Или нажмите **"Пропустить"** — перейти к OCR без обработки

**Логика контроля качества:**

- **Уровень искажений ≤ 15%** → автоматическая предобработка
- **Уровень искажений > 15%**:
  - Система предложит улучшить читаемость
  - Если "Да" → предобработка
  - Если "Нет" → спросит "Принудительно запустить?"
    - "Да" → предобработка
    - "Нет" → спросит "Пропустить предобработку?"
      - "Да" → переход к OCR без обработки
      - "Нет" → остановка

---

### Этап 3: 🔍 OCR

**Цель:** Распознать текст с чертежа

**Порядок действий:**

1. Выберите чертеж из списка (PDF отобразится справа)
2. При необходимости укажите **страницы для OCR** (поле справа внизу)
3. Нажмите:
   - **"Запустить OCR"** — автоматическое распознавание (EasyOCR)
   - **"Вручную"** — заполнить данные вручную
4. Дождитесь распознавания (10-60 секунд)
5. Результат сохраняется в PRO (таблица БД)
6. Автоматический переход к этапу 4

---

### Этап 4: ✅ Проверка

**Цель:** Проверить и валидировать данные

**Порядок действий:**

1. Просмотрите распознанные данные
2. При необходимости нажмите **"Редактировать"** — исправьте данные
3. Нажмите **"Валидировать → FRO"** — создаётся:
   - Запись в таблице FRO (финальный результат)
   - Запись в таблице ARCH_OF_DRAWS (архив)

### Взаимодействие с PDF

- **Автоматическая загрузка**: при выборе чертежа из списка PDF отображается справа
- **Перетаскивание (drag)**: зажмите левую кнопку мыши и двигайте в любую сторону
- **Масштаб**: крутите колёсико мыши вверх (увеличить) или вниз (уменьшить)
- **Кнопка "Сброс"**: возвращает вид в исходное положение

## Выбор страниц для OCR

В правой нижней части формы есть поле **"Страницы:"** для выбора какие страницы PDF распознавать.

### Форматы ввода:

| Ввод         | Описание                      | Пример       |
| ---------------- | ------------------------------------- | ------------------ |
| Число       | Одна страница             | `1` или `5` |
| Диапазон | Несколько подряд       | `1-8`            |
| Список     | Конкретные страницы | `1,3,7`          |
| Все           | Все страницы PDF           | `все`         |

**Примеры:**

- `1` — только первая страница
- `1,3,5` — страницы 1, 3 и 5
- `1-8` — страницы с 1 по 8
- `все` — все страницы документа

## Таблицы и структура БД

В системе используется **8 таблиц**.

### Схема связей между таблицами

```
EMPLOYEES
    │
    ├──→ SKETCH_DRAWINGS (idEmployee)
    ├──→ PRIMARY_DRAWINGS (idEmployee)
    ├──→ PRO (validated_by)
    └──→ ARCH_OF_DRAWS (id_employeePrmArch)

SKETCH_DRAWINGS ──────→ PRIMARY_DRAWINGS (AssociatedWith → idSkDrav)
    │
PRIMARY_DRAWINGS ─────→ PRO (idPrimaryDrawing)
    │
PRO ─────────────────→ FRO (pro_id)
    │
FRO ─────────────────→ ARCH_OF_DRAWS (NumDravFROArch)
```

## Поток данных (workflow)

```
Загрузка PDF (Этап 1)
    ↓
SKETCH_DRAWINGS (эскиз)
    ↓
PRIMARY_DRAWINGS (первичный чертеж)
    ↓
Предобработка (Этап 2)
    → Оценка искажений
    → Бинаризация, выравнивание, удаление шума
    ↓
OCR (Этап 3)
    → Выбор страниц (1,3,7 или 1-8)
    → EasyOCR → извлечение текста
    ↓
PRO (результат распознавания)
    ↓
Проверка (Этап 4)
    → Редактирование данных
    → Валидация
    ↓
FRO (финальный результат) + ARCH_OF_DRAWS (архив)
```

## Возможные ошибки

| Ошибка                             | Решение                                                               |
| ---------------------------------------- | ---------------------------------------------------------------------------- |
| "Нет подключения к БД"  | Проверьте параметры подключения                 |
| "Выберите сотрудника"  | Нажмите "Сотрудник" и выберите сотрудника |
| "Модуль easyocr не найден" | Установите:`pip install easyocr`                                 |
| "Модуль fitz не найден"    | Установите:`pip install PyMuPDF`                                 |
| "Выберите чертеж"          | Выберите строку в списке слева                     |
| "Файл не найден"             | Проверьте путь к PDF-файлу                                |
| Ошибка SQL                         | Проверьте структуру таблиц в БД                   |
